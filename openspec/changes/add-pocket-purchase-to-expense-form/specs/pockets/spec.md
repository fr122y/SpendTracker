# Spec Delta

## ADDED Requirements

### Requirement: Record a pocket purchase from the expense journal form

Форма журнала операций MUST предлагать сценарий «Покупка из кармана», когда у пользователя есть хотя бы один неархивированный карман, и MUST NOT предлагать его, когда таких карманов нет. При выборе сценария форма MUST показывать выбор кармана, содержащий только неархивированные карманы пользователя, и MUST NOT добавлять операцию, пока карман не выбран. Если у пользователя ровно один неархивированный карман, он MUST быть выбран заранее; если их два или больше, выбор MUST начинаться пустым. Описание, сумма и категория MUST вводиться так же, как для личного расхода, включая подсказку категории по ключевым словам и ручной выбор. Операция MUST записываться на общую выбранную дату приложения; форма журнала MUST NOT предоставлять отдельное поле даты. Форма MUST NOT ограничивать сумму остатком кармана: покупка сохраняется и тогда, когда остаток становится отрицательным. Сохранённая операция MUST быть покупкой выбранного кармана, неотличимой по учёту от покупки, добавленной в виджете карманов. Форма журнала MUST NOT предоставлять перевод из кармана в расходы.

#### Scenario: Offer the scenario when an active pocket exists

- **GIVEN** у пользователя есть хотя бы один неархивированный карман
- **WHEN** пользователь открывает список сценариев формы журнала
- **THEN** в списке есть «Покупка из кармана»
- **AND** перевода из кармана в расходы в списке нет

#### Scenario: Hide the scenario without active pockets

- **GIVEN** у пользователя нет карманов или все его карманы архивированы
- **WHEN** пользователь открывает список сценариев формы журнала
- **THEN** сценария «Покупка из кармана» в списке нет
- **AND** остальные сценарии формы доступны как прежде

#### Scenario: List only active pockets

- **GIVEN** у пользователя есть один активный и один архивированный карман
- **WHEN** пользователь выбирает сценарий «Покупка из кармана»
- **THEN** появляется выбор кармана с активным карманом
- **AND** архивированный карман в выборе отсутствует
- **AND** поля даты в форме нет

#### Scenario: Preselect the only active pocket

- **GIVEN** у пользователя ровно один неархивированный карман
- **WHEN** пользователь выбирает сценарий «Покупка из кармана»
- **THEN** этот карман уже выбран в выборе кармана
- **AND** операцию можно добавить, не выбирая карман вручную

#### Scenario: Require a pocket choice among several

- **GIVEN** у пользователя два или больше неархивированных кармана, выбран сценарий «Покупка из кармана», заполнены описание, сумма и категория
- **WHEN** карман не выбран
- **THEN** выбор кармана пуст
- **AND** операция не добавляется, пока карман не выбран

#### Scenario: Record the purchase on the selected date

- **GIVEN** в приложении выбрана дата, выбран сценарий «Покупка из кармана» и активный карман
- **WHEN** пользователь вводит описание, сумму и категорию и добавляет операцию
- **THEN** покупка появляется в журнале за выбранную дату
- **AND** покупка появляется в истории покупок этого кармана за месяц выбранной даты с теми же описанием, суммой, датой и категорией
- **AND** использованная сумма кармана увеличивается, а остаток уменьшается на сумму покупки

#### Scenario: Account for the purchase like one made in the pockets widget

- **GIVEN** покупка из кармана на 1 000 ₽ добавлена через форму журнала
- **WHEN** система показывает общие расходы и личный недельный операционный бюджет
- **THEN** покупка входит в общие расходы и расходы своей категории
- **AND** покупка не входит в личный недельный операционный расход

#### Scenario: Allow a purchase beyond the remaining amount

- **GIVEN** остаток кармана за месяц выбранной даты равен 500 ₽
- **WHEN** пользователь добавляет через форму журнала покупку из этого кармана на 2 000 ₽
- **THEN** покупка сохраняется без предупреждения и блокировки
- **AND** остаток кармана становится равным −1 500 ₽

#### Scenario: Suggest or manually choose the purchase category

- **GIVEN** выбран сценарий «Покупка из кармана»
- **WHEN** пользователь вводит описание
- **THEN** при совпадении с сохранённым keyword mapping категория показывается как подсказка, которую можно изменить
- **AND** при отсутствии совпадения доступен ручной выбор категории, без которого операция не добавляется
- **AND** ручной выбор сохраняется как keyword mapping для будущих описаний
