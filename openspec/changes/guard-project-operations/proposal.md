# Proposal

## Why

Прожарка приложения 2026-10-15 (задача T-041) нашла дефекты операций проектов. Возврат в проект не ограничен суммой «На руках»: взято 5000, возвращено 7000 — карточка показывает «На руках» 0, а лишние 2000 теряются. Без проектов журнал предлагает проектные сценарии и выводит пустой выбор «Выберите проект», из которого нельзя выйти к созданию проекта. Форма создания проекта остаётся открытой после создания, а при переименовании кармана видны две кнопки «Отмена».

Владелец решил (2026-10-15): возврат больше «На руках» запрещён в форме и на сервере; без проектов журнал не предлагает проектные операции или ведёт к созданию проекта; форма проекта закрывается после создания; без миграций.

## What Changes

- «На руках» проекта — сумма взятых из проекта денег минус возвращённые; проектные расходы её не меняют (как в `getProjectCashOnHand`).
- Server Actions `addExpense`, `updateExpense` и `deleteExpense` для взятия и возврата проекта блокируют строку проекта (`SELECT … FOR UPDATE`) в транзакции и отклоняют операцию, после которой «На руках» стала бы отрицательной.
- Формы журнала и проекта показывают ошибку «Нельзя вернуть больше, чем на руках: N ₽» и не отправляют такой возврат.
- Без проектов журнал не показывает проектные сценарии и выводит подсказку о создании проекта в разделе «Проекты».
- Форма создания проекта закрывается после создания; при переименовании кармана остаётся одна кнопка «Отмена».

Вне объёма: закрытие и архив проекта (T-059), пояснение влияния проекта на недельный бюджет, миграции.

Удаление, после которого «На руках» стала бы отрицательной, отклоняется: `deleteExpense` возвращает `project_cash_negative`, оптимистичное удаление откатывается с сообщением «Нельзя удалить: на руках станет меньше 0 — сначала удалите возврат».

Риски: правка или удаление старых операций, после которых «На руках» уже отрицательна, требует сначала исправить баланс.

## Capabilities

### New Capabilities

- `projects`: операции проекта и ограничение возврата суммой «На руках».

### Modified Capabilities

Нет.

## Impact

- `src/shared/api/expense-actions.ts`, новый `src/shared/api/project-helpers.ts`.
- `src/features/add-expense`, `src/features/manage-projects`, `src/widgets/projects`, `src/widgets/pockets`.
- Unit-тесты слайсов, e2e `e2e/expenses.spec.ts` (без записи данных). Схема базы данных не меняется.
