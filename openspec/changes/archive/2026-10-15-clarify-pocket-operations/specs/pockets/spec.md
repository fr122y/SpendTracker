## ADDED Requirements

### Requirement: Explain the effect of pocket operations in forms

Форма покупки из кармана в виджете карманов и сценарий «Покупка из кармана» формы журнала MUST показывать однострочную подсказку «Покупка из кармана: входит в «Анализ» и расходы дня, недельный бюджет не тратит». Форма перевода в расходы MUST показывать однострочную подсказку «Перевод в расходы: пополняет недельный бюджет этой недели на сумму перевода, в «Анализ» не входит». Формы MUST NOT показывать отдельное поле или строку даты и MUST NOT ограничивать сумму остатком кармана.

#### Scenario: Explain a purchase in the pockets widget

- **GIVEN** пользователь открыл форму покупки в виджете карманов
- **THEN** форма показывает подсказку покупки
- **AND** не показывает подсказку перевода

#### Scenario: Explain a transfer in the pockets widget

- **GIVEN** пользователь открыл форму перевода в расходы в виджете карманов
- **THEN** форма показывает подсказку перевода
- **AND** не показывает подсказку покупки

#### Scenario: Explain a purchase in the journal form

- **GIVEN** в форме журнала выбран сценарий «Покупка из кармана»
- **THEN** форма показывает подсказку покупки

## MODIFIED Requirements

### Requirement: Show the pocket name on expense journal cards

Карточка операции в журнале операций MUST показывать имя кармана для покупки из кармана в виде «Из кармана: <имя>». Карточка перевода из кармана MUST показывать строку категории «Перевод из кармана» и в бейдже только имя кармана, без повторения фразы «Перевод из кармана»; рамка и сумма карточки перевода MUST оформляться отлично от карточек расходов. Имя архивированного кармана MUST показываться так же, как имя активного. Пока список карманов загружается, карточка операции кармана MUST показывать на месте бейджа заглушку фиксированной ширины и MUST NOT показывать общий бейдж без имени. Если список карманов не загрузился или не содержит карман операции, карточка MUST показывать значок без имени: «Покупка из кармана» для покупки и «Перевод из кармана» для перевода. Журнал MUST NOT ждать загрузки списка карманов, чтобы показать операции. Карточки операций, не связанных с карманом, MUST NOT изменяться.

#### Scenario: Show the pocket name on a purchase card

- **GIVEN** в журнале за выбранную дату есть покупка из кармана «Кафе» и список карманов загружен
- **WHEN** пользователь смотрит карточку этой операции
- **THEN** карточка показывает «Из кармана: Кафе»

#### Scenario: Show the pocket name on a transfer card

- **GIVEN** в журнале за выбранную дату есть перевод из кармана «Подарки» и список карманов загружен
- **WHEN** пользователь смотрит карточку этой операции
- **THEN** карточка показывает строку категории «Перевод из кармана» и бейдж «Подарки»
- **AND** фраза «Перевод из кармана» на карточке встречается один раз
- **AND** карточка оформлена отлично от карточки расхода

#### Scenario: Keep the name of an archived pocket

- **GIVEN** в журнале есть операция кармана, который позже архивирован
- **WHEN** пользователь смотрит карточку этой операции
- **THEN** карточка показывает имя архивированного кармана

#### Scenario: Show a placeholder while pockets load

- **GIVEN** список карманов ещё загружается
- **WHEN** журнал показывает покупку и перевод из кармана
- **THEN** на месте бейджа кармана показывается заглушка
- **AND** общий бейдж «Покупка из кармана» не показывается
- **AND** операции журнала видны и доступны для действий

#### Scenario: Fall back when the pocket name is unavailable

- **GIVEN** список карманов не загрузился или не содержит карман операции
- **WHEN** журнал показывает покупку и перевод из кармана
- **THEN** карточка покупки показывает «Покупка из кармана»
- **AND** карточка перевода показывает «Перевод из кармана»
- **AND** операции журнала видны и доступны для действий

#### Scenario: Leave other operation cards unchanged

- **GIVEN** в журнале есть личный, проектный или общий расход
- **WHEN** список карманов загружен
- **THEN** карточка такой операции не показывает имя кармана
