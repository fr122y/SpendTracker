# Design

## Decisions

- `numeric(12,2)` вмещает 100 000 000,00 с запасом; `mode: 'number'` в Drizzle 0.45 превращает строку драйвера в `Number` при чтении и передаёт `String(value)` при записи.
- Приведение `round("col"::double precision::numeric, 2)`: прямое `real::numeric` оставляет 6 значащих цифр (12345.67 → 12345.7), через float8 значение сохраняется. На повторном запуске колонка уже `numeric(12,2)`, и то же приведение возвращает то же значение.
- Новые ограничения сначала удаляются (`DROP CONSTRAINT IF EXISTS`), затем колонки меняют тип, затем ограничения добавляются `NOT VALID`. Файл можно запустить повторно, и старые строки production не роняют миграцию. Без `BEGIN`/`COMMIT`: раннер выполняет файл одним неявным запросом.
- Правило операции: `amount > 0 OR (operationType = 'pocket_transfer' AND amount = 0)`, как в `updateExpense`. Ограничение на `user_settings.weeklyLimit` не добавляется: приложение пишет туда только умолчание 10000, действующий лимит хранится в `weekly_budget_limit`.
- Округление выполняется до проверки, поэтому сохраняется ровно проверенное значение.
- Совместимость: новый код работает на старой схеме (`real` принимает строку числа и возвращает число). Старый код работает на новой схеме: `PgReal.mapFromDriverValue` разбирает строку `numeric` через `parseFloat`.
