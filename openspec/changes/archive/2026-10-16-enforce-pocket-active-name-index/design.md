# Design

## Decisions

- Выражение индекса `lower(btrim("name"))` повторяет нормализацию приложения: имя хранится без краевых пробелов, сравнение без учёта регистра.
- Обычный `CREATE UNIQUE INDEX`, не `CONCURRENTLY`: раннер миграций выполняет файл в неявной транзакции, а таблица `pocket` маленькая.
- Проверка под блокировкой остаётся: она возвращает имя конфликтующего кармана. Индекс — последняя линия защиты; его нарушение ловится вне транзакции (транзакция после ошибки уже прервана) по коду `23505` и имени ограничения, в том числе в `cause` ошибки Drizzle, и возвращает `name_conflict` с введённым именем.
- Новый код работает и на старой схеме: без индекса нарушение просто не возникает.
