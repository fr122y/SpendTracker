# Proposal

## Why

Страница /account только показывает данные: сменить имя или пароль нельзя. Способ входа показан сырым id «Credentials», надзаголовок «Account» по-английски, в тексте опечатка «вернет». Задача T-048.

## What Changes

- Форма смены имени: имя обрезается по краям, длина от 2 до 50 символов, как при регистрации. Новое имя сразу видно на странице; имя в JWT обновляется через `unstable_update` Auth.js.
- Форма смены пароля для аккаунтов с паролем: «Текущий пароль», «Новый пароль», «Повторите новый пароль». Текущий пароль проверяется через bcrypt, новый проходит правила регистрации, совпадает с повтором и отличается от текущего; хеш bcrypt cost 12.
- Страница полностью по-русски: «Аккаунт», «Эл. почта», способ входа «Email и пароль», «вернёт».

Критерии приёмки: имя и пароль меняются на /account; ошибки показаны понятными русскими сообщениями без технических деталей; на странице нет «Credentials» и «Account».

Вне объёма: завершение других сессий при смене пароля (стратегия JWT, без изменения схемы невозможно); ограничение частоты попыток (в проекте его нет ни для входа, ни для сброса); смена email.

Риски: после смены пароля уже выданные JWT других устройств остаются действительными до истечения.

## Capabilities

### New Capabilities

- `account`: просмотр и изменение имени и пароля в личном кабинете.

### Modified Capabilities

Нет.

## Impact

- `src/app/account/` (страница, формы, server actions, тесты).
- `src/shared/lib/credentials-schema.ts` — общие правила имени и пароля для регистрации, сброса и аккаунта.
- `src/shared/auth` — экспорт `unstable_update`, обработка `trigger: 'update'` в `jwt`, флаг `hasPassword` и русская подпись способа входа.
