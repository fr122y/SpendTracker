# Proposal

## Why

Карточка операции в журнале помечает покупку и перевод из кармана значком «Покупка из кармана» или «Перевод из кармана», но не говорит, из какого кармана. При нескольких карманах пользователь не может понять по журналу, какой из них затронут, и вынужден сверяться с историей в виджете «Карманы».

## What Changes

- На карточке операции журнала значок покупки из кармана показывает имя кармана: «Из кармана: Кафе».
- Значок перевода из кармана показывает имя кармана: «Перевод из кармана: Кафе».
- Имя архивированного кармана показывается так же, как имя активного: история сохраняется.
- Пока список карманов не загружен или карман в нём не найден, значок остаётся прежним: «Покупка из кармана» или «Перевод из кармана».

Критерии приёмки:

- В журнале карточка покупки из кармана «Кафе» показывает «Из кармана: Кафе», карточка перевода — «Перевод из кармана: Кафе».
- Для операции архивированного кармана показывается его имя.
- Без загруженного списка карманов карточки показывают прежние значки и остаются рабочими.
- Карточки остальных операций не меняются.

Вне рамок:

- Форма журнала и форма операции виджета «Карманы».
- Карточки в истории виджета «Карманы»: история открыта внутри одного кармана, имя уже видно в заголовке, значки остаются прежними.
- Обработка дат, Server Actions, схема данных.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `pockets`: добавляется требование показывать имя кармана на карточке операции журнала.

## Impact

- `src/entities/expense/ui`: `ExpenseCard` получает необязательное свойство `pocketName`, `ExpenseList` — необязательное `pocketNames` (имя по идентификатору кармана). Сущность `expense` не импортирует `@/entities/pocket`: имя приходит свойством.
- `src/widgets/expense-log`: `ExpenseLog` читает карманы через `usePockets()` и передаёт имена в список. Слайс начинает импортировать `@/entities/pocket` — допустимое по FSD направление `widgets -> entities`.
- Тесты и README обоих слайсов.
- Серверная часть, схема данных и зависимости не меняются. `usePockets()` уже используется на dashboard, запрос разделяет кеш TanStack Query.

Риски:

- Список карманов загружается асинхронно: до загрузки карточка показывает прежний значок, затем имя. Журнал не ждёт карманы и не блокируется при ошибке их запроса.
- Длинное имя кармана удлиняет значок; строка метаданных карточки уже переносится.
