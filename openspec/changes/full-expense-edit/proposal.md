# Proposal

## Why

В журнале у расхода меняется только сумма: опечатку в описании, неверную категорию или дату можно исправить лишь удалением и повторным вводом. Удаление подтверждается без названия записи и не отменяется. В деталях категории аналитики строки не кликабельны. Задача T-044: расход правится целиком, включая перенос на другой день или месяц.

## What Changes

- Диалог «Изменить операцию» (`features/edit-expense`) меняет сумму, описание, категорию и дату одним вызовом `updateExpense` с существующей серверной проверкой. Открывается кнопкой на карточке журнала и из строки деталей категории.
- Диалог повторяет серверные ограничения: у общего расхода категория заблокирована с подсказкой; у перевода из кармана категория заблокирована, сумма может стать 0; у движения проектных денег меняются только описание и дата; операция архивного кармана открывается только для чтения.
- После правки список операций перечитывается; журнал, итоги, аналитика и недельный бюджет обоих периодов строятся из него. Для операций кармана перечитываются и бюджеты кармана.
- Подтверждение удаления называет запись: описание, сумму и дату. В журнале удаление откладывается на 5 с: строка скрывается сразу, тост «Расход удалён · Отменить» отменяет удаление; при уходе со страницы или размонтировании ожидающие удаления выполняются сразу.
- Смена категории не создаёт правило ключевых слов (это T-047).

Вне объёма: разделитель тысяч в суммах строк и русские aria-label кнопок (T-056); undo в разделах проектов и карманов.

## Capabilities

### New Capabilities

- `expense-editing`: правка операции целиком и удаление с отменой.

### Modified Capabilities

- `spending-analysis`: строки деталей категории открывают редактор вместо режима только для чтения.

## Impact

- `src/features/edit-expense/`, `src/entities/expense/` (карточка, список, запросы, отложенное удаление), `src/widgets/expense-log/`, `src/widgets/analysis/`, их тесты. Схема базы данных и Server Actions не меняются.
