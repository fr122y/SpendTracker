# Proposal

## Why

Недельный бюджет показывает неточные и непонятные суммы. При перерасходе потраченное упирается в лимит («4 000 / 4 000» при реальных 4 760,5), а «Осталось −760,5» дублирует «Сверх бюджета 760,5». Остаток считается от лимита плюс пополнения из проектов и карманов, но пополнения не видны, поэтому «Осталось 3 365,5» при «6 134,5 / 8 000» не объяснить. Строки «Покрыто проектами/карманами 0 ₽» непонятны. Лимит 0 принимается. Неделя нового лимита в `updateSettings` считается по часам сервера (UTC): в UTC+10 в понедельник утром лимит попадает в прошлую неделю. Label «Лимит» не связан с полем. Задача T-042 в реестре задач владельца.

## What Changes

- Сводка недели показывает реальную потраченную сумму и эффективный лимит (лимит + пополнения недели): «Личный бюджет: 4 760,5 ₽ / 4 000 ₽». Если пополнения есть, под сводкой строка «Лимит X ₽ + пополнения Y ₽».
- Перерасход — одна строка «Сверх бюджета: X ₽» вместо «Осталось»; «Осталось» показывается только в пределах бюджета и не бывает отрицательным. То же для общего бюджета.
- Метрики пополнений показываются только при ненулевом пополнении: «Пополнение из проектов» / «Переводы из карманов» с подписью «ушло на перерасход: X ₽» вместо отдельных строк «Покрыто проектами/карманами».
- Лимит должен быть > 0: форма показывает inline-ошибку «Лимит должен быть больше 0» и не сохраняет 0 или отрицательное значение; Server Actions `setWeeklyLimitForWeek` и `updateSettings` отклоняют такой лимит.
- То же правило > 0 для лимита общего бюджета при создании и изменении: inline-ошибка в форме; `createSharedBudget` и `setSharedWeeklyLimitForWeek` отклоняют 0, отрицательное и нечисловое значение до любой записи (решение владельца 2026-10-15).
- Неделя нового лимита приходит с клиента как локальный понедельник `YYYY-MM-DD`; сервер проверяет формат и что это понедельник. `updateSettings` с `weeklyLimit` требует `weeklyLimitWeekStart` и больше не берёт неделю из часов сервера. Старые строки не переписываются.
- Label «Лимит» связан с полем (`htmlFor`/`id`) в личном и общем бюджете.

Вне рамок: история недель, миграции и `CHECK`-ограничения, исправление уже сохранённых строк.

## Capabilities

### New Capabilities

- `weekly-budget`: сводка недельного бюджета и редактирование личного недельного лимита.

### Modified Capabilities

None.

## Impact

`src/widgets/weekly-budget`, `src/shared/lib/finance-selectors.ts` (новые чистые функции), `src/shared/api/settings-actions.ts`, `src/shared/api/shared-budget-actions.ts`, unit/UI тесты и `e2e/dashboard.spec.ts`. Схема базы данных и зависимости не меняются.
