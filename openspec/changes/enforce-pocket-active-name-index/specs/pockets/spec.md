# Spec Delta

## MODIFIED Requirements

### Requirement: Keep active pocket names unique

Система MUST отклонять создание кармана и переименование кармана, если у пользователя есть другой активный карман с тем же именем после удаления краевых пробелов и без учёта регистра, в том числе при прямом вызове серверного действия. База данных MUST гарантировать это правило для активных карманов уникальным индексом, а его нарушение MUST возвращаться как тот же конфликт имени. Отклонённое действие MUST NOT менять сохранённые карманы, и интерфейс MUST показывать сообщение «Карман с таким названием уже есть». Имя архивированного кармана MUST быть доступно для нового или переименованного активного кармана. Изменение только регистра или краевых пробелов собственного имени кармана MUST разрешаться.

#### Scenario: Reject a duplicate name on create

- **GIVEN** у пользователя есть активный карман «Отпуск»
- **WHEN** пользователь создаёт карман « оТПУСК »
- **THEN** новый карман не создаётся
- **AND** форма показывает «Карман с таким названием уже есть»

#### Scenario: Reject a duplicate name on rename

- **GIVEN** у пользователя есть активные карманы «Отпуск» и «Подарки»
- **WHEN** пользователь переименовывает «Подарки» в «отпуск»
- **THEN** карман сохраняет имя «Подарки»
- **AND** форма показывает «Карман с таким названием уже есть»

#### Scenario: Reuse the name of an archived pocket

- **GIVEN** карман «Ремонт» архивирован, и активного кармана с этим именем нет
- **WHEN** пользователь создаёт карман «ремонт»
- **THEN** карман создаётся

#### Scenario: Reject a duplicate name on the server

- **GIVEN** у пользователя есть активный карман «Отпуск»
- **WHEN** клиент напрямую вызывает создание кармана «отпуск», в том числе одновременно с другим таким вызовом
- **THEN** сервер возвращает отказ из-за конфликта имени, и активным остаётся один карман с этим именем

#### Scenario: Reject a duplicate active name in the database

- **GIVEN** у пользователя есть активный карман «Отпуск»
- **WHEN** запись в обход проверки приложения делает активным ещё один карман «отпуск»
- **THEN** база данных отклоняет запись, и серверное действие возвращает конфликт имени
