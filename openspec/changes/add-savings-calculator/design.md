# Design

## Context

Суммы «Накоплений» считаются в `features/manage-buckets/lib/allocation.ts` в копейках: доход — `useSettingsStore().salary` (рубли), категории — `useBucketStore().buckets` (канонический процент). FSD запрещает импорт feature → feature. В `shared/ui` нет диалога общего назначения (только `ConfirmDialog`) и нет нижней панели; `useViewport` из `shared/lib` различает mobile (< 768px).

## Goals / Non-Goals

**Goals:** компактный калькулятор с экранной клавиатурой, чипами «Накоплений» и копированием результата; суммы совпадают с виджетом до копейки.

**Non-Goals:** клавиатурный ввод, история, сохранение состояния, другие источники значений, изменения БД и Server Actions.

## Decisions

- **Расчёт распределения в `shared/lib/allocation.ts`.** Файл переносится без изменений, `manage-buckets/lib/allocation.ts` реэкспортирует его, поэтому существующие тесты и поведение редактора не меняются. Альтернатива — `entities/bucket` — ломала бы тесты `BucketEditor`, которые мокают `@/entities/bucket` целиком; функции чистые и зависят только от `shared/types`.
- **Слайс `features/calculator`.** `lib/expression.ts` — чистые операции над строкой выражения (внутренние операторы `* /`, отображение `× ÷ −`), вычисление через `evaluateMathExpression` и округление до копеек; `lib/savings-values.ts` — чипы в копейках и перевод копеек в рубли целочисленно, без плавающей точки. UI — `CalculatorLauncher` (кнопка + панель), состояние выражения локальное (`useState`), глобального состояния нет.
- **Вставка значения.** Если выражение заканчивается числом, вставка заменяет это число; после `)` вставка добавляет `×`; иначе дописывает. Отрицательное значение вставляется в скобках.
- **Презентация.** Своя разметка на Tailwind без новых зависимостей: `role="dialog"` по центру на широком экране и нижняя панель с ручкой и обработкой `touchstart/touchend` (свайп вниз > 80px закрывает) на узком.
- **Монтирование.** `CalculatorLauncher` рендерится в `_pages/dashboard` — единственном экране приложения после входа.
- **Копирование.** `navigator.clipboard.writeText` с форматом `12345.67`; подтверждение «Скопировано» на 2 секунды, при ошибке — «Не удалось скопировать».

## Risks / Trade-offs

- Кнопка может перекрыть контент в правом нижнем углу → небольшой размер (48px), отступ от края, `z-40` ниже модальных окон.
- Свайп реализован упрощённо (без анимации следования за пальцем) — достаточно для закрытия, без новой библиотеки.
