# Design

## Context

Суммы «Накоплений» считаются в `features/manage-buckets/lib/allocation.ts` в копейках: доход — `useSettingsStore().salary` (рубли), категории — `useBucketStore().buckets` (канонический процент). FSD запрещает импорт feature → feature. В `shared/ui` нет диалога общего назначения (только `ConfirmDialog`) и нет нижней панели; `useViewport` из `shared/lib` различает mobile (< 768px). На мобильном прокручивается контейнер `[data-grid-container]` виджета `dashboard-grid`.

## Goals / Non-Goals

**Goals:** компактный калькулятор с экранной клавиатурой и курсором, живыми значениями «Накоплений», сохранением выражения в браузере и копированием результата; суммы совпадают с виджетом до копейки.

**Non-Goals:** клавиатурный ввод, история, другие источники значений, изменения БД и Server Actions.

## Decisions

- **Расчёт распределения в `shared/lib/allocation.ts`.** Файл переносится без изменений, `manage-buckets/lib/allocation.ts` реэкспортирует его. Альтернатива — `entities/bucket` — ломала бы тесты `BucketEditor`, которые мокают `@/entities/bucket` целиком.
- **Модель выражения — список токенов.** Символьный токен (`{ kind: 'char', value }`: цифра, `.`, оператор, скобка) и токен значения (`{ kind: 'savings', id, label, lastKopecks }`). Курсор — индекс между токенами, поэтому значение атомарно: стрелки перепрыгивают его, backspace удаляет целиком, а цифры редактируются посимвольно. Строка для `evaluateMathExpression` собирается из токенов по текущим суммам (`income`, `bucket:<id>`, `operations`); отсутствующий id берёт `lastKopecks`, который обновляется при каждом действии с известными суммами.
- **Автоматический `+`.** Значение, вставленное сразу после числа, другого значения или `)`, получает `+` перед собой; если сразу после курсора стоит число или значение, `+` добавляется и после него. Цифра после значения `+` не получает: неясно, хочет ли пользователь дописать новое число или умножить, — выражение просто станет некорректным и покажет `—`.
- **Сокращение названий.** Чистая функция `abbreviateLabel` по практике ГОСТ Р 7.0.12-2011: обрезка после согласной перед гласной, не на «й/ь/ъ», не короче 2 букв, с точкой; скобки и служебные слова отбрасываются; слова без кириллицы и числа сохраняются. Самый короткий уровень по таблице владельца: первое значимое слово сокращается; второе слово двусловного названия даёт инициал («Мес. д.»); в более длинных названиях остальные кириллические слова отбрасываются («Отп. 2027»). Это отходит от общего правила «слова до 4 букв не сокращаются» и «не короче 2 букв» для второго слова — таблица владельца приоритетнее.
- **Состояние в Reatom.** `calculatorAtom` (`{ tokens, caret }`) расширен `withLocalStorage({ key: 'smartspend-calculator-v1' })` из `@reatom/core`; `fromSnapshot` прогоняет данные через `sanitizeCalculatorState`, так что повреждённые записи дают пустое выражение. React читает атом через `useSyncExternalStore`, как `layout-editor`. Синхронизация без `useEffect`. `CalculatorLauncher` подключается через `next/dynamic` с `ssr: false`.
- **Презентация.** Своя разметка на Tailwind без новых зависимостей: диалог над кнопкой на широком экране и нижняя панель на узком. Свайп обрабатывается и touch-, и pointer-событиями (кроме мыши); порог — чистая функция `shouldCloseOnSwipe` (> 80px вниз). Пока панель открыта, `overflow: hidden` ставится на `html`, `body` и `[data-grid-container]` и восстанавливается при закрытии.
- **Чипы.** Без общего ограничения ширины: сумма видна всегда, ограничено только название (`max-w-[11rem]`, ≈176px при 12px шрифте): «Операции (остаток)» ≈ 115px, «Месячный доход» ≈ 95px помещаются, длинные названия обрезаются.
- **Копирование.** Иконка в строке результата, `navigator.clipboard.writeText` в формате `12345.67`; иконка меняется на галочку на 2 секунды, `aria-live` сообщает «Скопировано» или «Не удалось скопировать».

## Risks / Trade-offs

- Кнопка может перекрыть контент в правом нижнем углу → небольшой размер, `z-40`, скрыта, пока калькулятор открыт.
- Сохранённое выражение хранит названия и последние суммы категорий в `localStorage` браузера — это не новые данные, они уже видны на экране.
- Сокращения по таблице владельца могут совпасть у разных категорий; полное название доступно в подсказке элемента.
