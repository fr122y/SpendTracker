# Design

## Context

`PocketOperationForm` получает `selectedDate` от виджета `PocketsSection`, который читает его из `useSessionStore`. Форма копирует дату в локальное состояние при монтировании и показывает её в поле `type="date"`. Виджет перемонтирует форму при смене кармана, типа операции или месяца, но не при смене дня внутри месяца.

## Goals / Non-Goals

**Goals:**

- Убрать поле даты из формы новой операции кармана.
- Сохранять операцию на выбранную дату dashboard.

**Non-Goals:**

- Менять редактирование существующих операций, обычный журнал расходов, Server Actions или схему данных.
- Менять props или экспорт `PocketOperationForm`.

## Decisions

- Форма не хранит дату в состоянии, а вычисляет `formatDate(selectedDate)` из prop в момент отправки. Альтернатива — оставить локальное состояние без поля — сохранила бы устаревшую дату, если день dashboard изменён при открытой форме.
- Prop `selectedDate` остаётся: источником даты по-прежнему служит виджет, а feature-слой не начинает читать store сам.

## Risks / Trade-offs

- Операцию на другую дату теперь нельзя записать без смены даты dashboard. Это принятое правило единой даты.
- Сценарий сохраняет прежнее имя «Add an operation with an editable date», хотя дата больше не редактируется: `openspec validate` отклоняет блок MODIFIED, в котором нет сценария с именем из текущей спецификации, а операции переименования сценария нет. Содержимое сценария описывает новое поведение.
