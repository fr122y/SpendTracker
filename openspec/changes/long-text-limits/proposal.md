# Proposal

## Why

Прожарка 2026-10-15 (T-053): описание расхода и имя категории не ограничены по длине. Имя категории из 90 символов без пробелов ломает плитку «Анализа» и даёт горизонтальный скролл; описание из 500 символов растягивает строку журнала до 6006 px. На телефоне сумма и удаление уходят за экран, итог журнала переносится, плитки «Покупки/Переводы» карманов на 1280 px налезают, а первый тап по плитке «Анализа» показывает тултип и не открывает диалог.

## What Changes

- Лимиты в одном месте (`src/shared/lib/text-limits.ts`): описание операции ≤ 200 символов, имя категории ≤ 40 символов. Символ — единица длины строки JavaScript (UTF-16), как у атрибута `maxLength`, поэтому поле и сервер считают одинаково.
- Поля ввода (добавление расхода, проектная операция, операция кармана, диалог правки, личные и общие категории) получают `maxLength` и сообщение под полем.
- Server Actions `addExpense`, `updateExpense`, `addCategory`, `updateCategory`, `addSharedBudgetCategory`, `updateSharedBudgetCategory` отклоняют длинный текст с русским сообщением.
- Старые записи длиннее лимита остаются как есть и отображаются обрезанными. Правка такой записи требует сократить поле, только если пользователь его меняет.
- Строка журнала обрезает описание и категорию (`min-w-0`, `truncate`), сумма и кнопки не сжимаются; полный текст — в `title` и в диалоге правки. Итог журнала и «Анализа» не переносится.
- Плитки «Анализа» обрезают подпись; тултип показывается только мышью и не перехватывает тапы.
- Плитки «Покупки/Переводы» карманов переходят в одну колонку, когда им тесно, и не переносят сумму.

Вне объёма: ограничение в базе данных и миграция; внешний контейнер и прокрутка журнала, аккордеон и сетка дашборда (T-051); шапка (T-050).

## Capabilities

### Modified Capabilities

- `expense-editing`: лимит длины описания.
- `categories`: лимит длины имени категории.
- `spending-analysis`: длинные подписи плиток и тап по плитке.

## Impact

- `src/shared/lib/text-limits.ts`, `src/shared/api/{expense,category,shared-category}-actions.ts`, формы в `src/features/*`, `src/entities/expense/ui/expense-card.tsx`, `src/widgets/{expense-log,analysis,pockets}`, тесты и e2e `e2e/long-names.spec.ts`. Схема базы данных не меняется, миграции нет.
