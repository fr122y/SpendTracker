# Proposal

## Why

В редакторе раскладки дашборда можно только перетаскивать виджеты и менять ширину колонок. Ненужный виджет нельзя убрать, а запутанную раскладку нельзя вернуть к исходной. Задача T-049.

## What Changes

- В режиме редактирования у каждого виджета на десктопе есть кнопка «Скрыть виджет». Скрытый виджет не показывается ни на десктопе, ни на планшете, ни на мобильном. Последний видимый виджет скрыть нельзя.
- В режиме редактирования показывается панель «Скрытые виджеты» с русскими названиями скрытых виджетов и кнопкой «Показать». Возвращённый виджет встаёт на своё место в исходной колонке, иначе в конец этой колонки.
- Кнопка «Сбросить раскладку» с подтверждением возвращает исходную раскладку и показывает все виджеты.
- `LayoutConfig` получает необязательное поле `hidden`, которое хранится в существующем jsonb `layout_config.config`. Миграции БД нет. Старые конфигурации без поля читаются как «ничего не скрыто»; неизвестные id отбрасываются; новый виджет, которого нет ни в колонках, ни в `hidden`, показывается.
- `updateLayoutConfig` отклоняет `hidden`, который не массив, содержит неизвестный id или скрывает все виджеты.

Вне объёма (остаются открытыми, прожарка #24/#25): resize на pointer events с превью, разные имена ручек перетаскивания, клавиатурная перестановка, `aria-orientation`.

## Capabilities

### New Capabilities

- `dashboard-layout`: скрытие и возврат виджетов, сброс раскладки.

### Modified Capabilities

Нет.
